# 悬浮图片2（FloatPicture2）

**当前版本：2.0.9.4**

<p>
  <img src="docs/logo-colored.jpg" alt="FloatPicture Logo" width="140" align="left" hspace="20">
  <strong>安卓悬浮参考图工具（Floating Reference Image Tool for Android）</strong><br><br>
  将照片或彩色线稿悬浮在相机、录像、绘画等应用上方，通过调整位置、大小、角度与透明度，辅助拍摄构图、姿态对齐、绘画临摹和比例检查。

<br clear="left">

本仓库名称为“悬浮图片2（FloatPicture2）”，应用内名称为“悬浮图片（FloatPicture）”。项目名称中的“2”用于区分原作者的项目，不代表当前版本号。

| 项目 | 说明 |
| --- | --- |
| 系统要求 | Android 4.4（API 19）及以上；旧版数据文件夹导入需要 Android 5.0 及以上 |
| 图片格式 | JPG/JPEG、PNG、WebP、BMP、GIF（作为静态图）；HEIC/HEIF 的导入取决于设备系统的解码支持 |
| 界面语言 | 简体中文、英语、西班牙语、巴西葡萄牙语、印度尼西亚语、日语、俄语、阿拉伯语；可跟随系统或手动选择 |
| 图片处理 | 在设备本地完成，图片不会上传 |

## 快速开始

1. 打开应用，按提示完成隐私确认并允许悬浮窗显示。
2. 从相册或文件选择器导入参考图片，例如已拍摄的照片、动作参考或分镜截图。
3. 在图片设置中调整大小、位置、角度和透明度；需要轮廓参考时，选择“生成彩色线稿参考图”。
4. 开启图片悬浮，切换到相机、录像或绘画应用，对照参考图调整构图、姿态或画面比例。
5. 需要在其他应用中调整图片时，在全局设置中开启小圆点控制器及相应手势功能；调整后通过控制器保存。

## 当前版本功能

### 彩色线稿与相册导出

在图片设置的“通用设置”中选择“生成彩色线稿参考图”，可将照片转换为轮廓参考：

- **六种颜色**：红、绿、蓝、青、黑、白，可根据相机画面或画布背景选择。
- **线条调整**：调节线条范围与对比度，并实时查看预览。
- **背景选择**：默认使用透明背景，也可勾选保留 18% 灰色背景。
- **参数记忆**：按图片保存成功应用的线条范围、对比度、颜色及灰底选项，重新打开时恢复；取消调整不会覆盖已保存的参数。新导入的图片保存到图库后也会保留这些设置。
- **保留原图**：后续调整从保留的原图重新生成，避免在线稿上重复处理；可移除线稿并恢复原图。
- **导出到相册**：点击“导出到相册”即可按当前参数生成并应用线稿，再将完整尺寸 PNG 保存到 `Pictures/FloatPicture`，无需先点击“应用到图片”。未勾选灰底时保留透明背景，导出使用完整图片而非缩小的预览图。

Android 9 及以下导出时可能需要授予存储权限。相册中的导出图片独立保存，卸载应用后仍会保留。

### 图片大小、位置、角度与透明度

图片设置支持滑块调整和数值输入，适合需要精确对齐的构图与绘画参考。

| 调整项 | 功能 |
| --- | --- |
| 大小 | 调整宽高像素或缩放比例，缩放精度为 0.001 倍；可锁定原始比例 |
| 位置 | 调整屏幕坐标，支持滑块和数字输入；控制器方向盘可按 1 像素移动 |
| 角度 | 滑块覆盖 -360° 至 360°，以 0° 为中点；支持 0.01° 精度输入，负数表示逆时针旋转 |
| 透明度 | 在 0–1 之间调整，方便同时看清参考图与下方画面 |

主界面会显示每张图片的缩放、位置和旋转摘要，便于检查当前参数。

### 悬浮显示与手势控制

- **单图模式**：一次显示一张参考图，打开另一张时自动关闭上一张。
- **多图模式**：让多张图片同时悬浮，组合不同的动作、构图或绘画参考。
- **手势调整**：支持单指拖动、以双指位置为中心缩放及双指旋转，移动缩放与旋转可分别开关。
- **保存与撤销**：开启“保存手势信息到图片”后，可通过小圆点控制器保存当前调整，或放弃未保存的变化并恢复上次状态。
- **保存后锁定**：保存成功后自动关闭移动缩放和旋转，减少误触。
- **图片溢出屏幕**：可在全局设置或控制器中切换，方便只显示参考图的局部区域。

手势选项位于 **全局设置 → 手势功能设置**。参考层可随时显示或隐藏，方便检查实际画面。

### 悬浮小圆点控制器

在 **全局设置 → 通用设置 → 显示小圆点控制器** 中开启。小圆点可拖动并吸附到屏幕上、下、左、右边缘，横竖屏切换后保持所在边缘与相对位置。展开后可：

- 切换上一张或下一张参考图，显示或隐藏当前图片。
- 开关手势移动缩放、手势旋转及图片溢出屏幕。
- 保存当前调整，或撤销未保存的调整。
- 使用圆形方向盘按 1 像素移动图片，使用旋转盘调整角度。
- 快速显示或隐藏应用主界面。

控制器保持在悬浮图片上方，便于随时操作。通知栏显示当前图片状态，并提供控制器开关。

### 图片管理

- **命名与排序**：为参考图片设置名称，管理多张图片及其显示顺序。
- **保留参数替换图片**：更换参考图时保留位置、缩放、旋转与透明度，方便连续创作。
- **另存为副本**：复制当前图片、变换信息及线稿参数，再独立编辑或替换副本图片，快速复用同一布局。
- **导入质量设置**：可在全局设置中预先设定新图片的导入质量，默认 80%；更改后仅影响后续导入。

### 备份、恢复与旧版迁移

入口：**全局设置 → 通用设置 → 导出备份 / 导入恢复数据**。

- **导出备份**：将图片、线稿原图、图片顺序及已保存的图片参数导出为 `.fpbackup.zip`，包括位置、缩放、旋转、透明度和线稿设置；不包含通用设置。导出前请保存需要保留的手势调整。
- **恢复备份**：选择备份文件，检查通过并确认后整体替换当前图库。需要保留当前图库时，请先另行导出。
- **旧版迁移**：可选择旧版 `FloatPicture` 文件夹或其上一级目录，导入其中的图片和设置。
- **完整性检查**：校验备份中的数据与图片，损坏、缺失或不支持的备份不会直接覆盖图库；替换失败时尝试恢复之前的图库。

备份请保存到“下载”等应用专属目录之外的位置，确认导出成功后再卸载。卸载前未导出的应用内数据无法通过重新安装找回。每份备份最多包含 10,000 个数据/图片文件，未压缩总大小不超过 2 GB，导入导出需要足够的本机临时空间。备份不加密；选择云盘时由相应文件提供方处理存储与传输。

详见[备份与恢复说明](docs/BACKUP_AND_RESTORE.md)。

### 多语言与隐私

可在全局设置中选择跟随系统，或手动切换八种界面语言；应用内隐私政策随所选语言显示。

图片导入、线稿生成与导出均在本机完成，应用不上传图片。首次使用会展示隐私说明，后续可在应用内查看隐私政策、版权与开源许可。应用已关闭系统自动备份；需要迁移或重装时，可使用应用内的备份功能。

## 适用场景

- **拍摄与姿态对齐**：对照参考照片调整人物站位、动作、比例和留白，适合摄影、自拍及三脚架拍摄。
- **固定构图与系列记录**：用于穿搭对比、商品展示、前后对比、每日记录和重复机位拍摄。
- **短视频与静物创作**：参考分镜或动作关键帧，调整人物、商品、餐饮或桌面物品的位置。
- **绘画临摹与写生**：将照片或线稿悬浮在画布上方，观察轮廓、结构、透视和比例关系。

本应用提供视觉对照与手动调整，不具备自动人像识别、姿势正确性判断或相机自动控制功能。
