# 线稿设置保存与回显修复

线稿窗口原先每次打开都会把线条范围设为 2、对比度设为 65，颜色回到红色，灰底默认勾选。
生成线稿时仅保存图片，没有记录生成参数。

现在按图片保存线条范围、对比度、颜色和灰底选项，打开时恢复上次成功应用的设置。
参数写入现有 `PictureData.list`，退出编辑页后仍保留，也随现有图库备份保存。
新图片默认使用透明背景，不勾选灰底；用户主动勾选并保存后，再打开仍保持勾选。
取消参数调整不覆盖上次保存的设置。新导入图片在加入图库时保存参数；另存副本时复制参数。

旧版没有记录的参数无法从已生成图片中还原，需要重新设置并保存一次。
