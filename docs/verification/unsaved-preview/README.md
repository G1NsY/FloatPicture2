# 未保存图片悬浮残留修复

未保存的导入预览不在已保存图片的窗口注册表中，原先仅在编辑页主动返回时清理。
通过多任务切走后，再由悬浮控制器用 CLEAR_TOP 返回主页，会销毁编辑页，但漏掉预览窗口。

现在未保存预览随编辑页暂停、用户离开或失去焦点而隐藏，返回原编辑页时恢复。
编辑页销毁或取消导入时，移除普通预览、调整预览并清理临时图片；已保存图片继续正常悬浮。
导入异步完成时检查编辑页状态，关闭后只清理，后台完成时保持隐藏。加载未完成时不能保存。
移除旧的 WINDOW_CREATED 恢复标记，避免编辑页重建后跳过加载而留下空白编辑状态。

部分系统的实时多任务页仍让编辑页处于 RESUMED 状态，因此同时处理焦点和用户离开事件。
编辑页自身的调整弹窗取得焦点时保持预览，切出时隐藏弹窗。
