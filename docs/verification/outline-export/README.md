# 线稿应用后导出到相册

在线稿设置的滑块下方新增“导出到相册”按钮。点击后读取当前线条范围、对比度、颜色和灰底选项，先生成并应用线稿、保存参数，再将同一张完整尺寸图片导出为 PNG 到 `Pictures/FloatPicture`。
无需先点击“应用到图片”。导出保留透明度，不使用缩小的预览图，也不读取上次保存的线稿。

Android 10 及以上使用 MediaStore，完成写入后才发布图片；写入或发布失败时清理未完成条目。Android 9 及以下保存到公共 Pictures 目录并通知媒体扫描，在 Android 6–9 上按需申请写入权限。拒绝权限不会应用或导出图片。
存储权限声明限制在 API 28 及以下；实现依据 [Android 共享媒体存储说明](https://developer.android.com/training/data-storage/shared/media)。

应用图片失败时不导出；应用成功、相册导出失败时明确提示状态并允许重试，保留原图供重试或取消线稿使用。导出过程中禁用按钮，避免重复点击。
新导入但尚未加入图库的图片可导出到相册，之后保存到图库会保留当前线稿参数。已有图片导出后直接保存参数，再次进入仍回显。
界面文案和本地图片导出说明覆盖现有八种界面语言，隐私说明补充旧系统存储权限及导出图片的存储位置和保留方式。
